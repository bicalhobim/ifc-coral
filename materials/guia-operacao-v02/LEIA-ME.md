# Guia de operação do IFC Coral

Professor Lucas Bicalho

Comece pelo **5.6 IFC Coral - Guia de operacao passo a passo.pdf** ou pelo PowerPoint de mesmo nome. São 23 passos para você testar a interface local. Os números sobre as telas correspondem às instruções ao lado.

1. Abra http://127.0.0.1:5178/.
2. Se já houver um trabalho seu, exporte pelo menu Arquivos antes de iniciar outro.
3. Para seguir do zero, use Novo projeto, Abrir TORRE02 e Criar caso de concretagem.
4. Para conferir o resultado pronto, reabra Exemplo-concluido.IFC-Coral.json pelo menu Arquivos.

O exemplo usa elementos reais da TORRE02 e premissas fictícias de 12 m³, datas e fornecedores. O PPC de 100% corresponde a 1 compromisso concluído no prazo no ensaio. Não é dado de uma obra em execução.

O JSON portátil inclui o modelo IFC e as decisões. O navegador guarda uma cópia automática local. Nenhuma chave de IA faz parte do exemplo. O apoio de IA é opcional; chamadas reais com credenciais ainda precisam ser validadas.

O roteiro Markdown, roteiro.json e a pasta prints guardam o conteúdo e as capturas desta edição. Interface-v02.jpg mostra a visão geral. As capturas vieram de uma origem de teste separada para preservar o trabalho do professor.
